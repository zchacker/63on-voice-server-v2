# leaveRoom

**الاتجاه:** من العميل إلى الخادم.

## الإدخال

بلا حمولة:

    socket.emit("leaveRoom");

## المخرجات

لا يوجد إقرار مباشر. تستقبل الغرفة:
- userList بعد إزالة socket.
- micUpdate فقط إذا تم إخلاء مقعد مايك.

يغادر socket غرفة Socket.IO وتمسح حقول الغرفة والمستخدم لديه. تحذف رتبة المشرف المؤقتة حين يغادر آخر اتصال للمستخدم الغرفة. تبقى رتبة المشرف الثابتة وعلامات الإشراف في ذاكرة العملية.

يرسل Node أيضًا إشعار `left` داخليًا إلى Laravel لتحديث عداد الغرفة المحفوظ. راجعوا [عقد الحضور المطلوب من Laravel](../../../../LARAVEL_ROOM_PRESENCE_REQUEST.md).

إذا لم يكن socket داخل غرفة، فالطلب بلا أثر.

## المصدر

socket/users/user.events.js وuser.service.js وsocket/rooms/room.service.js.

## اتصال LiveKit

ينظف هذا الحدث حالة Socket.IO ولا يغلق اتصال LiveKit المستقل. عند مغادرة الغرفة عمدًا غادروا LiveKit عبر SDK أيضًا. عند الانقطاع عالجوا حالة كل اتصال بصورة مستقلة؛ راجعوا [دليل LiveKit](../livekit.md).
