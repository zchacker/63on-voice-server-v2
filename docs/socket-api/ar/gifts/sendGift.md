# sendGift

**الاتجاه:** من العميل إلى الخادم.

## الإدخال

أي حمولة هدية يتفق عليها فريق الواجهة والمنتج. لا يفرض الخادم schema للهدية. يجب أن يكون socket قد انضم لغرفة.

    socket.emit("sendGift", { "id": "gift-1", "name": "Rose" });

## مخرج النجاح

تستقبل كل sockets في الغرفة، بما فيها المرسل:

    { "gift": <القيمة المرسلة>, "user": <مستخدم هذا socket> }

ضمن الحدث sendGift.

## الرفض

يستقبل المرسل giftRejected { code: "NOT_IN_ROOM", message } إن لم يكن منضمًا.

## قيد مهم

الحدث يبث البيانات فقط. لا يتحقق الخادم من توفر الهدية أو ملكيتها أو سعرها أو الدفع أو الرصيد، ولا يحفظ الهدية.
